A UI icon in Material Symbols Outlined — the same set the app draws, so a mock matches the build.

```jsx
<Icon name="chevron_right" size={20} tone="faint" />
<Icon name="cottage" size={22} fill={1} tone="ink" />
```

- Outlined at rest, filled only for the selected tab.
- 24px is the default; 20px inside rows, 22px in the tab bar.
- Astronomical marks are NOT icons — use `Glyph`.
