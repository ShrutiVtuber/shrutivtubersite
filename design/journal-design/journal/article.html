Nothing was ever retrograde

A chart correct in every particular except one, and a zero that looked exactly like an answer.

By Shruti · 25 August 2026 EphemerisBugs

A chart was coming out right in every particular except one. Every planet was direct — all of them, at every date I tried, in every house system. A birth chart with no retrogrades is not wrong the way a crash is wrong. It is wrong the way a stopped clock is wrong: it reads plausibly, twice a day.

The shape of the bug

Swiss Ephemeris fills the speed slot only when it is asked to. Ask for a position without FLG_SPEED and you get a position, correct to the arcsecond, along with a zero where the daily motion should be.

xx, ret = swe.calc_ut(jd, swe.MOON, swe.FLG_SWIEPH)
speed    = xx[3]        # 0.0 — never computed
retrograde = speed < 0.0

Zero is not less than zero. So nothing was ever retrograde — not because the arithmetic was wrong, but because the input was a plausible-looking zero rather than a missing value.

A number that was never computed should not be able to reach a comparison. If it can, the comparison is not the bug.— from the commit message

Why it survived

Nothing threw. No test failed, because the tests asserted positions and the positions were right. The Moon's daily motion read 0.00°/day, which looks like a formatting problem rather than an absence, and I read it as one for two days.2

The test that would have caught it

One assertion over a date I already knew by heart: Mercury stations retrograde on 9 August 2026, and any build that says otherwise is not asking for speed. It is now the first test in the suite, and the only one whose failure I have already seen.

The fix, and the rule

- xx, ret = swe.calc_ut(jd, body, FLG_SWIEPH)
+ xx, ret = swe.calc_ut(jd, body, FLG_SWIEPH | FLG_SPEED)
+ if not flags & FLG_SPEED:
+     raise Unreckonable("speed was not requested")

The one-line change is the flag. The change that matters is the second one: the ephemeris layer now refuses to hand back a field it never computed. Unreckonable is the same exception the calendars raise at the pole on a day the sun does not rise — the instruments would rather say οὐ λογίζεται, it is not reckoned, than return a number nobody derived.1

A note on daily motion

The Moon's motion runs from roughly 11°/day to 15°/day and never rests. Sanskrit astronomy names the retrograde condition वक्री (vakrī, crooked) — a description of apparent motion, not a verdict on it. Zero was never a plausible value for either tradition to report.

What changed in the instrument

The chart page now prints ℞ beside a retrograde body, states the flag it ran under in its provenance card, and shows an em dash with a footnote where the speed field is absent. A chart that cannot know is more useful than a chart that guesses.
