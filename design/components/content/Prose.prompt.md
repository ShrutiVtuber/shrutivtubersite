Long-form typography wrapper — EB Garamond at 19/1.72, 66ch measure. `hr` renders as an asterism (⁂), blockquotes take a rose rule, code sits on the inset surface. `byline="Soror Eu. A."` closes magickal writing with the ruled seal. This is the journal spec BeeRanked must match.

```jsx
  <h2>On the hours of Hekate</h2>

</Prose>
```
