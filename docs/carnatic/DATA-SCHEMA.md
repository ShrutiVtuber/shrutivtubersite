# Swara Studio: the shape of the published data

Generated by `scripts/carnatic/describe_data.py` from a build of the data;
do not edit by hand. What each file is for, how to download it and how to
tell when it changed are in [API.md §2](API.md#2-the-schools-data-offline-download).

Described from data format 1, digest `8ddc5478c70604ae`.

`?` marks a key not every object has. `null` in a union means the key is
present with no value: show nothing for it.
